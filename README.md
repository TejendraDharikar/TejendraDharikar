**The short version:** I build things on the web and I don't stop halfway.

Most of what lives on this profile started the same way — an idea I couldn't shake, opened as an empty
folder somewhere past midnight, and pushed until it actually ran. Not because anyone assigned it. Because
not knowing *how* something works bothers me more than the hours it takes to find out.

What I care about when I write code:

- **Types over guesswork.** If TypeScript can catch it, TypeScript should catch it.
- **State you can reason about.** Predictable data flow beats clever data flow, every time.
- **Speed as a feature.** A fast UI isn't a nice-to-have — it's the whole experience.
- **Readable structure.** Six months from now, someone has to open this file. Usually me.

Still early in the journey, still deep in the grind — and that's exactly where I want to be. Every repo
here is a checkpoint, not a finished statement.
